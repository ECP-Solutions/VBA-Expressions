# LibreOffice 24.2 compatibility
## Bug fixed
- [x] Expressions with variables returned an empty result, and `Eval` called without arguments raised "Data type mismatch", on LibreOffice 24.2. There, an omitted optional `String` parameter with an empty default fails in comparisons; `Eval`, `GetPredInterArr` and `AppendToCBbuffer` now set it explicitly.
